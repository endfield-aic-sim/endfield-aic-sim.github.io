# 엔드필드 AIC 시뮬레이터

명일방주: 엔드필드의 AIC 공장을 브라우저에서 짜 보는 비공식 팬 제작 시뮬레이터입니다.

- 설비 배치, 벨트·파이프 연결, 창고 입출력 라인, 암관, 전력
- 원자재 소비량·산출물의 분당·시간당 표
- 범위 선택 → 복사·삭제·청사진 저장, 코드(`AIC2:`)로 청사진·레이아웃 공유
- 협곡 IV·무릉 부지 크기 (거점 40×40, 협곡 IV 허브 70×70, 무릉 시 80×80)

Hypergryph·Gryphline과 관계없는 팬 제작 도구이며, 게임 이름과 설비 이름의 권리는 각 권리자에게 있습니다.
